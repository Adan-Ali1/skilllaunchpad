Privacy

This website is an informational starter site. It currently has no accounts, contact forms, newsletter signup, analytics, or advertising.

The pages load font files from Google Fonts to display the selected typefaces. When a page loads those fonts, your browser makes a request to Google. If this changes, this page should be updated to explain any added data collection, cookies, forms, analytics, advertising, or affiliate links before they are enabled.

The downloadable planner is a static text file and does not ask for personal details.
